# Sistema de Contatos em Java

Aplicação de console para cadastro de contatos, desenvolvida para praticar Programação Orientada a Objetos em Java. O projeto implementa um CRUD completo (inserir, listar, atualizar e apagar) usando herança, interface genérica e o padrão DAO, com os dados armazenados em memória por meio de um `ArrayList`.

**Tecnologias e conceitos:** Java, POO, herança, interfaces, generics, padrão DAO e coleções.
